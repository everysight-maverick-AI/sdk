# Maverick AI / AI Pro SDK Tools

This folder contains scripts and tools that support the SDK.

Available tools:

| Tool | Description |
|------|-------------|
| [image_convert](./image_convert/) | Convert PNG/JPG images to the format and resolution supported by the glasses display (8-bit or 16-bit) 
| [font2sif](./font2sif/) | Convert TrueType (.ttf) and OpenType (.otf) fonts to SIF2 format for the glasses 
| [simulator](./simulator/) | Maverick AI Glasses Simulator 

More information can be found in our [developers portal](https://everysight.github.io/maverick-ai-docs/)
